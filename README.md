# Big Data Assignment: MNIST Dataset

## Objective
To load, view, and preprocess the MNIST handwritten digit dataset using Python in Google Colab.

## Tasks Performed
1. Loaded the MNIST dataset from the provided URL.
2. Inspected dataset shapes, data types, and pixel values.
3. Visualized handwritten digit images and their labels.
4. Normalized pixel values from 0–255 to 0–1.
5. Applied Gaussian Blur as an optional image preprocessing technique.
6. Verified the processed data.

## Tools Used
- Python
- NumPy
- Matplotlib
- OpenCV
- Google Colab

## Dataset
[MNIST Dataset](https://storage.googleapis.com/tensorflow/tf-keras-datasets/mnist.npz)

## Conclusion
The dataset was successfully loaded, visualized, and preprocessed. The original data was preserved for comparison with the processed data.
